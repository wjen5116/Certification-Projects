Certification Project Tracker

Change log

v2.4.6 Sep 25, 2026 Current

Added

  • Add customer button below the customer list, for starting a new customer.
  • Changes saved in the editor show up straight away in other tracker tabs open in the same browser.
  • Tracker pages check for the latest data when you return to their tab.
  • A note at the top of the editor when it's already open in another tab.

Changed

  • Customers are listed alphabetically.
  • Customer counts in the sidebar include only open certifications. Customers with none show a grey 0.
  • Completed certifications show a green Completed tag next to the serial number instead of a check mark.
  • Each customer's Add certification button is now Add project, with the customer filled in.

v2.4.5 Sep 25, 2026

Added

  • Mark a certification complete. Completed certifications get a green check in the sidebar, move to the bottom of each customer's list, and show the date they were completed.
  • New Completed count in the summary boxes. Completed certifications no longer count as overdue or due soon.
  • This change log, linked from the version number at the bottom of each page.
  • Deleting a certification now asks for confirmation first.

Changed

  • Some certification details are now shown only in the editor.
  • Behind-the-scenes tidy-up of the page code. No visible changes.

Fixed

  • Signing in from the view-only page now opens the editor in its new location.

v2.4.4 Sep 2026

Added

  • Certification names are generated automatically from the authority, level, aircraft and SIM model. You can still type your own name.
  • SIM model field, read automatically from the SIM serial number.

Changed

  • Certifications in the sidebar use grey shading when hovered or selected.
  • Settings gear is Redbird red, with a red outline on hover.
  • Removed the “Certifications” heading above the customer list.

v2.4.3 Sep 2026

Changed

  • Dark mode: the selected customer is highlighted in Redbird red.
  • Edit, View and Add buttons get a blue outline on hover. Red is now reserved for Delete.
  • Save buttons, links, the settings gear and focus outlines are blue.

Fixed

  • Form fields no longer take on the red page background in light mode.

  • Document names are plain text instead of links.
